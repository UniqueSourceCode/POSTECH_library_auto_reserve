POSTECH 청암 도서관 자동 예약 시스템

**중요**
이 코드는 포스텍 도서관 포털 사이트가 pniToken을 인증하지 않는 보안문제를 사용함.
추후에 이 버그가 패치가 된다면 이 코드도 수정 예정

사용방법 :
코드 위에 있는 username에 자신의 ID를 넣고, 원하는 자리를 코멘트를 참고하여 적기

기능 :
-pniToken을 인증하지 않는다는 버그로, 자신의 포스텍ID로 도서관에 로그인함
-현재 예약을 취소하고, 다음 예약을 함.

개발 동기 :
시험기간에 예약을 4시간마다 다시 해야하지만, 까먹을 때가 있어서 자동화를 하고 싶었습니다.


AI 사용 여부:
사이트 pniToken security issue를 찾고, 어떤 좌석을 정확히 예약하는 방법은 devTool로 확인하고 직접 코드 플로우를 작성하였습니다.
나머지 손노동만 AI로 대신하였습니다.
